# Campus Events

Campus Events is a simple web application where users can interact with a click counter.

## How to start the server

Open a terminal in the folder containing `hello.js` and run:


node hello.js


The server runs at http://localhost:3000.

## How to start the client

Open another terminal in the Angular project folder and run:


ng serve


Open http://localhost:4200 in your browser to use the application.
